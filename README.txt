EDITOR HUB — APK-READY ANDROID PROJECT
==========================================
This project wraps the EDITOR HUB web editor prototype inside an Android WebView.

Build:
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Build > Build APK(s).
4. Install app-debug.apk on an Android phone.

Requirements:
- Android Studio
- Internet connection for first Gradle dependency download
- Android SDK 35

The app uses the supplied icon and original EDITOR HUB prototype UI.
It is not a copy of CapCut's proprietary code/assets.
